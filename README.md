# 과제 4: 외부 데이터 모니터링 대시보드 (USGS 전 세계 지진 실시간 관제)

미국 지질조사국(USGS)의 공개 실시간 지진 피드(`all_day.geojson`)를 기반으로 **최근 24시간 전 세계 지진 발생 건수(`건`)**를 추적하고, **내장 관제형 세계지도(SVG)** 위에 최신 지진 진앙지를 **네온 레이더 파동(반짝임 비콘)**으로 실시간 시각화하는 대시보드입니다.

---

## 1. 파일 구성
- [index.html](index.html): 카드 1 ~ 카드 5 전체 요구사항(`T04-C01` ~ `T04-C28`)이 반영된 메인 대시보드 화면
- [styles.css](styles.css): 다크모드 지진 관제 센터 테마 및 진앙지 레이더 파동(`@keyframes radar-expand`, `core-blink`), `FRESH`/`STALE` 상태 스타일
- [world-map-data.js](world-map-data.js): 오프라인(`T04-C15`) 및 시크릿 창(`T04-C01`)에서 외부 타일 서버나 API 키 없이 100% 동작하는 내장 세계지도 대륙/조산대 좌표 데이터
- [app.js](app.js): 실시간 USGS API 호출, `Asia/Seoul(KST)` 기준 `YYYY-MM-DD` 고유키 일별 기록 Upsert, 5대 실패 합성 재현(`Fixture`), 복구 재생, 전일 대비 변화 재계산 및 원본·저장값·화면값 1:1 대조 로직
- [data/daily-records.json](data/daily-records.json): 정적 배포 환경 및 시크릿 창에서 일별 기록을 함께 불러올 수 있는 데이터 파일

---

## 2. 과제 조건(`T04-C01` ~ `T04-C28`) 충족 내역

### 카드 1 & 카드 2: 매일 추적할 값 선정 및 비밀키 없는 API 호출
- **`T04-C01` (시크릿 창 무인증 열람)**: 결과물 대시보드와 소스 URL(`https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_day.geojson`) 모두 로그인이나 인증 없이 시크릿 창에서 즉시 열립니다.
- **`T04-C03` (실제로 변하는 공개 데이터)**: USGS `all_day.geojson`의 `metadata.count`(최근 24시간 전 세계 지진 총 발생 건수) 및 최신 지진 좌표(`features[0].geometry.coordinates`)를 실시간 조회합니다.
- **`T04-C04` ~ `T04-C09` (필수 표시 항목)**:
  - **값(`T04-C04`)**: 최근 24시간 지진 발생 건수 (예: `284`)
  - **단위(`T04-C05`)**: `건`
  - **출처(`T04-C06`)**: `USGS (미국 지질조사국) Earthquake Hazards Program` 및 원본 URL 링크
  - **출처 시각(`T04-C07`)**: USGS `metadata.generated` 시각 (`YYYY-MM-DD HH:mm:ss KST`)
  - **조회 시각(`T04-C08`)**: 클라이언트 수신 시각 (`YYYY-MM-DD HH:mm:ss KST`)
  - **기준 시간대(`T04-C09`)**: `Asia/Seoul (UTC+09:00, KST)`
- **`T04-C10` (원본·저장값·화면값 일치)**: 하단 **정합성 1:1 대조 인스펙터**에서 원본 응답 발췌본, `localStorage` 저장값, DOM 화면 표시값을 나란히 대조하고 자동 일치 여부를 검증합니다.
- **`T04-C11` (비밀키 원문 0건)**: USGS 공개 API는 인증키가 필요 없으며, 브라우저 코드·배포 파일·네트워크·Git 기록 어디에도 비밀키가 존재하지 않습니다.
- **`T04-C25` · `T04-C26`**: 개인정보 0건이며, 실패 재현에는 100% 합성 테스트 데이터(`SYNTHETIC_FAULT_FIXTURES`)만 사용합니다.

### 카드 3: 실패 유형 다섯 가지 재현 및 Stale/복구 검증
- **`T04-C12` ~ `T04-C16` (5대 실패 별도 상태 표시)**:
  1. `TIMEOUT` — 응답 지연 (Timeout)
  2. `AUTH_401_403` — 401/403 접근 거부
  3. `RATE_LIMIT_429` — 429 호출 제한 (Rate Limit)
  4. `OFFLINE` — 네트워크 오프라인
  5. `SCHEMA_MISMATCH` — 응답 형식(Schema) 변경
- **`T04-C17` · `T04-C18` (마지막 정상값 유지 및 `stale` 표시)**: 실패 발생 시 기존 정상 수치와 세계지도 위 진앙지 마커를 지우지 않고 유지하며, 상단 및 카드 배지를 `stale (오래된 값)`로 전환합니다.
- **`T04-C19` (재시도 동작 및 복구 Fixture 재생)**: 실패 상태에서 재시도 버튼과 **복구 Fixture 재생** 버튼을 제공하며, 복구 Fixture 재생 시 재시도 진행 표시 후 `fresh / none`으로 복귀하고 **다음 날짜(KST +1일) 일별 기록 1건이 추가**됩니다.

### 카드 4: 하루 1건의 일별 기록
- **`T04-C20` (같은 KST 날짜 중복 방지)**: `Asia/Seoul` 기준 `YYYY-MM-DD`를 고유키(`dateKST`)로 사용하여 같은 날 여러 번 조회에 성공해도 행이 늘어나지 않고 해당 날짜 기록 1건만 최신값으로 덮어씁니다.
- **`T04-C21` (다음 KST 날짜 신규 기록 생성)**: 기준 시간대의 다음 날짜에 성공하면 새로운 `YYYY-MM-DD` 키로 일별 기록 행이 추가됩니다.

### 카드 5: 실제 날짜 2일의 기록과 전일 대비 변화
- **`T04-C22` ~ `T04-C24`**: 서로 다른 `Asia/Seoul` 날짜의 기록 2건을 날짜순으로 정렬하여 `전일 대비 변화량(당일 값 - 전일 값)`과 `변화율(%)`을 계산하고 재계산 검증식을 함께 표시합니다.

## 3. 짧은 확인 방법 4줄 (`T04-C27`)
1. **① 어디로**: 새 시크릿 창(무인증 상태)에서 본 대시보드 결과물 URL과 상단 출처의 USGS 원본 GeoJSON 소스 URL(`https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_day.geojson`)에 각각 접속합니다.
2. **② 3단계 이내 절차**: (1단계) 페이지 진입 시 자동 조회된 최근 24시간 지진 건수·단위(`건`)·KST 시각 및 세계지도 점멸 좌표를 확인하고, (2단계) 카드 3의 5가지 실패 버튼 중 하나를 눌러 실패 상태와 마지막 정상값 유지(`stale`)를 확인한 뒤, (3단계) `복구 Fixture 재생`(또는 실시간 재조회)을 눌러 복구 및 일별 기록/전일 대비 변화를 확인합니다.
3. **③ 통과 시 표시**: 상단 배지가 `fresh` 및 `none (정상)`으로 표시되고, 세계지도 최신 진앙지에 네온 레이더 파동이 반짝이며, 원본 응답·저장값(`localStorage`)·화면 표시값 및 KST 고유키(`YYYY-MM-DD`) 일별 기록과 전일 대비 변화 재계산 결과가 `100% 일치`로 표시됩니다.
4. **④ 실패 시 표시**: 5가지 실패 유형별 고유 코드(`TIMEOUT`, `AUTH_401_403`, `RATE_LIMIT_429`, `OFFLINE`, `SCHEMA_MISMATCH`)가 별도 경고 배너로 표시되고, 기존 정상 수치와 지도 위 진앙지 마커는 지워지지 않은 채 `STALE (오래된 값)` 상태와 재시도 버튼이 활성화됩니다.

---

## 4. AI와 나의 판단 3줄 (`T04-C28`)
1. **① AI에게 맡긴 일**: USGS GeoJSON API 비동기 호출, 위도·경도 좌표(`[-180~180, -90~90]`)를 내장 SVG 세계지도 평면 좌표로 변환해 최신 진앙지에 레이더 파동(Pulse)을 렌더링하는 로직, 그리고 `Intl.DateTimeFormat('ko-KR', { timeZone: 'Asia/Seoul' })` 기반의 KST 날짜 키(`YYYY-MM-DD`) 계산 및 5종 합성 실패 Fixture 상태 전환 코드 작성을 맡겼습니다.
2. **② 직접 판단한 일**: 비밀키 노출 위험이 전혀 없는 USGS 지진 데이터를 선정하고, 단순 숫자 나열 대신 세계지도 위에서 새 지진 발생 위치가 반짝이는 관제형 UI 컨셉을 직접 기획했으며, 일별 대표 추적 지표를 전일 대비 증감 검증이 명확한 '최근 24시간 지진 발생 건수(`건`)'로 결정하고 실제 날짜(KST) 2일의 기록은 가짜 데이터 없이 실제 조회로 남기도록 설계 기준을 확정했습니다.
3. **③ 따르지 않은 AI 제안**: 외부 지도 타일 서버(Leaflet CDN 타일)를 불러오자는 대안과 2일 차 일별 기록을 처음부터 가짜(Mock) 날짜 데이터로 미리 채워 넣자는 방식은 각각 '오프라인 재현(`T04-C15`) 시 지도 깨짐 방지'와 '카드 5의 실제 날짜 조회 원칙(`T04-C22`) 준수'를 위해 따르지 않고, 오프라인에서도 100% 동작하는 내장 벡터 관제 세계지도와 실제 KST 날짜 누적 구조를 선택했습니다.
