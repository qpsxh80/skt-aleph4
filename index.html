📋 짧은 확인 방법 (4줄) T04-C27
① 어디로: 새 시크릿 창(무인증 상태)에서 본 대시보드 결과물 URL과 상단 출처의 USGS 원본 GeoJSON 소스 URL(all_day.geojson)에 각각 접속합니다.
② 3단계 이내 절차: (1단계) 페이지 진입 시 자동 조회된 최근 24시간 지진 건수·단위(건)·KST 시각 및 세계지도 점멸 좌표를 확인하고, (2단계) 카드 3의 5가지 실패 버튼 중 하나를 눌러 실패 상태와 마지막 정상값 유지(stale)를 확인한 뒤, (3단계) 복구 Fixture 재생(또는 실시간 재조회)을 눌러 복구 및 일별 기록/전일 대비 변화를 확인합니다.
③ 통과 시 표시: 상단 배지가 fresh 및 none (정상)으로 표시되고, 세계지도 최신 진앙지에 네온 레이더 파동이 반짝이며, 원본 응답·저장값(localStorage)·화면 표시값 및 KST 고유키(YYYY-MM-DD) 일별 기록과 전일 대비 변화 재계산 결과가 100% 일치로 표시됩니다.
④ 실패 시 표시: 5가지 실패 유형별 고유 코드(TIMEOUT, AUTH_401_403, RATE_LIMIT_429, OFFLINE, SCHEMA_MISMATCH)가 별도 경고 배너로 표시되고, 기존 정상 수치와 지도 위 진앙지 마커는 지워지지 않은 채 STALE (오래된 값) 상태와 재시도 버튼이 활성화됩니다.
🧠 AI와 나의 판단 (3줄) T04-C28
① AI에게 맡긴 일: USGS GeoJSON API 비동기 호출, 위도·경도 좌표(`[-180~180, -90~90]`)를 내장 SVG 세계지도 평면 좌표로 변환해 최신 진앙지에 레이더 파동(Pulse)을 렌더링하는 로직, 그리고 Intl.DateTimeFormat('ko-KR', { timeZone: 'Asia/Seoul' }) 기반의 KST 날짜 키(YYYY-MM-DD) 계산 및 5종 합성 실패 Fixture 상태 전환 코드 작성을 맡겼습니다.
② 직접 판단한 일: 비밀키 노출 위험이 전혀 없는 USGS 지진 데이터를 선정하고, 단순 숫자 나열 대신 세계지도 위에서 새 지진 발생 위치가 반짝이는 관제형 UI 컨셉을 직접 기획했으며, 일별 대표 추적 지표를 전일 대비 증감 검증이 명확한 '최근 24시간 지진 발생 건수(건)'로 결정하고 실제 날짜(KST) 2일의 기록은 가짜 데이터 없이 실제 조회로 남기도록 설계 기준을 확정했습니다.
③ 따르지 않은 AI 제안: 외부 지도 타일 서버(Leaflet CDN 타일)를 불러오자는 대안과 2일 차 일별 기록을 처음부터 가짜(Mock) 날짜 데이터로 미리 채워 넣자는 방식은 각각 '오프라인 재현(T04-C15) 시 지도 깨짐 방지'와 '카드 5의 실제 날짜 조회 원칙(T04-C22) 준수'를 위해 따르지 않고, 오프라인에서도 100% 동작하는 내장 벡터 관제 세계지도와 실제 KST 날짜 누적 구조를 선택했습니다.
