📋 짧은 확인 방법 (4줄) T04-C27
① 어디로: 새 시크릿 창(무인증 상태)에서 본 대시보드 결과물 URL과 하단 출처의 USGS 원본 GeoJSON 소스 URL(all_day.geojson)에 각각 접속합니다.
② 3단계 이내 절차: (1단계) 메인 화면의 최근 24시간 지진 건수·단위(건)·KST 시각 및 세계지도 신규 진앙지 점멸을 확인하고, (2단계) 왼쪽 탭(⚡)을 열어 5가지 실패 버튼 중 하나를 눌러 실패 상태와 마지막 정상값 유지(stale)를 확인한 뒤, (3단계) 복구 Fixture 재생을 눌러 복구 및 일별 기록/전일 대비 변화를 확인합니다.
③ 통과 시 표시: 상단 상태 배지가 fresh 및 none (정상)으로 표시되고, 새 지진 진앙지에만 레이더 불빛이 반짝이며, 원본·저장값·화면값과 KST 일별 기록 및 전일 대비 변화 재계산 결과가 100% 일치로 표시됩니다.
④ 실패 시 표시: 5가지 실패 유형별 고유 코드(TIMEOUT, AUTH_401_403, RATE_LIMIT_429, OFFLINE, SCHEMA_MISMATCH)가 상단 배지에 표시되고, 기존 정상 수치와 지도 좌표는 지워지지 않은 채 STALE (오래된 값) 상태와 재시도 버튼이 활성화됩니다.
🧠 AI와 나의 판단 (3줄) T04-C28
① AI에게 맡긴 일: USGS GeoJSON API 호출, 위경도 좌표를 내장 SVG 세계지도 평면 좌표로 변환해 신규 진앙지에 레이더 파동을 그리는 로직, 그리고 Asia/Seoul 기준 날짜 키(YYYY-MM-DD) 계산 및 5종 합성 실패 Fixture 상태 전환 코드 작성을 맡겼습니다.
② 직접 판단한 일: 비밀키가 불필요한 USGS 지진 데이터를 선정하고, 메인 화면에는 세계지도와 핵심 정보만 깔끔하게 남기고 상세 제어판은 왼쪽 슬라이드 탭으로 분리하는 UI 구조 및 '새로운 지진 데이터 유입 시에만 해당 진앙지가 반짝이도록' 하는 인터랙션 규칙을 직접 결정했습니다.
③ 따르지 않은 AI 제안: 과거 지진 점을 클릭할 때마다 반짝임 비콘이 이동하던 초기 제안과 외부 지도 타일(Leaflet CDN) 및 가짜 2일 차 초기 데이터를 넣자는 대안은 '신규 데이터 감지 알림의 명확성', '오프라인 재현(T04-C15) 시 지도 유지', '실제 날짜 조회 원칙(T04-C22)'을 위해 따르지 않았습니다.
