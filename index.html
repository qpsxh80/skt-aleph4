📋 짧은 확인 방법 (4줄) T04-C27
① 어디로 가나요: 계정 생성·로그인·인증·초대·비밀번호·OAuth·CAPTCHA 없이 새 시크릿 창에서 본 결과물 URL과 하단 출처의 USGS 공개 원천 URL(all_day.geojson)에 각각 접속합니다.
② 3단계 이내 무엇을 하나요: (1단계) 메인 화면에서 실시간 조회된 값·단위(건)·출처·출처 시각·조회 시각·기준 시간대(Asia/Seoul)와 세계지도 신규 진앙지 파동을 확인하고, (2단계) 왼쪽 ⚡ 탭을 열어 공식 9개 Fixture(D1-A, D1-B, D2 및 5대 실패 timeout·auth·rate_limit·offline·schema_error)를 재생한 뒤, (3단계) 다시 시도 행동(T04-RECOVER-D2)을 눌러 복구 및 일별 기록·어제 대비 변화를 확인합니다.
③ 무엇이 보이면 통과인가요: 정상 및 복구(T04-RECOVER-D2) 시 freshness: "fresh", error_code: "none"이 표시되고, 같은 날짜(2026-08-24) 재조회 시 행이 1건(값 105)으로 갱신되며 다음 날짜(2026-08-25) 성공 시 행이 2건(값 120, 어제 대비 변화 15)이 되고 원자료·저장값·화면값이 일치하면 통과입니다.
④ 안 될 때 무엇이 보이나요: 다섯 실패 재생 시 기존 정상값(105 또는 최신 지진 건수)과 일별 행이 지워지지 않은 채 freshness: "stale" 배지가 붙고, 원인에 따라 timeout, auth, rate_limit, offline, schema_error가 별도 실패 상태로 표시되며 다시 시도 버튼이 나타납니다.
🧠 AI와 나의 판단 (3줄) T04-C28
① AI에게 맡긴 일: USGS GeoJSON API 호출, Natural Earth 110m 세계지도 SVG 투영 및 마우스 휠 확대/축소 구현, 그리고 T04 공개 계약(normalized-reading.schema.json, reading-status.schema.json, 9개 결정론 Fixture 상태 전이) 코드 작성을 맡겼습니다.
② 학생이 직접 판단한 일: 비밀키가 불필요한 USGS 실시간 지진 데이터를 선정하고, 메인 화면에는 세계지도와 필수 정보만 깔끔하게 배치한 뒤 상세 제어판은 왼쪽 슬라이드 탭으로 숨기는 UI 구성, 점 크기를 20%로 줄이고 신규 지진 파동은 규모에 비례해 과장되게 표현하며 클릭한 지진 정보는 점 옆에 띄우는 시각적 규칙을 직접 결정했습니다.
③ AI 제안을 따르지 않은 일: 과거 지진 점을 클릭할 때마다 신규 감지 반짝임 비콘이 이동하던 초기 제안, 클릭 시 점 크기가 1.45배 커지던 효과, 그리고 임의의 대문자 오류 코드(AUTH_401_403 등)를 쓰던 방식은 '신규 지진 알림과의 혼동 방지', '정밀한 지도 점 표현', 'T04 공식 스키마(timeout, auth, rate_limit, offline, schema_error) 엄수'를 위해 따르지 않고 직접 수정을 지시했습니다.
